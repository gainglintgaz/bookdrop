2. **`CURRENT_SPRINT.md`** — live status: what's done, what's blocking, what's next.
3. **`golden-paths.md`** — "if you hit this situation, do exactly this" code patterns.

5. **`VACATION_QUEUE.md`** + **`PHONE_REVIEW.md`** — dispatchable task queue and the phone review/merge flow.

The frozen historical snapshot (engine inventory, export formats, the 2026-04-06 build status, cost/revenue tables, roadmap) lives in **`KNOWLEDGE_TRANSFER_ARCHIVE.md`** — useful for history, not current truth.
